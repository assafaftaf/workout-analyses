# Lap Tracker

מעקב אחרי מקטעי העבודה מאימוני אינטרוולים — NP, דופק וקדנס, מפוצל לפי אזור אימון.

## הרצה מקומית

```bash
pip install -r requirements.txt
streamlit run app.py
```

## מבנה

```
app.py                             הדאשבורד
analysis.py                        אומדן הסף וסיווג האזורים
theme.py                           שפת העיצוב
laps.csv                           הנתונים
scripts/garmin_auth.py             התחברות חד-פעמית ליצירת טוקן
scripts/sync_garmin.py             משיכת אימונים מ-Garmin Connect
scripts/requirements.txt           תלויות הסנכרון בלבד
.github/workflows/sync-garmin.yml  הרצה יומית ב-8:00
```

`requirements.txt` בשורש הוא של הדאשבורד ומכיל רק streamlit, pandas, numpy ו-plotly.
תלויות הסנכרון נפרדות כדי שלא ייטענו ב-Streamlit Cloud.

## חיבור Garmin

אין צורך ברישום אפליקציה ואין צורך במנוי. מתחברים פעם אחת מקומית,
ושומרים את הטוקן שנוצר כ-secret.

### 1. יצירת הטוקן

```bash
pip install garminconnect
python scripts/garmin_auth.py
```

הסקריפט מבקש אימייל, סיסמה, וקוד דו-שלבי אם מוגדר אצלך, ומדפיס מחרוזת base64.
הסיסמה לא נשמרת בשום מקום.

### 2. הגדרה בגיטהאב

**Settings → Secrets and variables → Actions**

תחת *Secrets*:

| שם | ערך |
|---|---|
| `GARMIN_TOKENS` | המחרוזת שהסקריפט הדפיס |

אופציונלי כגיבוי, אם הטוקן נפסל והרצה נכשלת: `GARMIN_EMAIL` ו-`GARMIN_PASSWORD`.
שים לב שהתחברות עם סיסמה מכתובת IP של גיטהאב עלולה לדרוש אימות דו-שלבי ולהיכשל,
ולכן הטוקן הוא הדרך המומלצת.

תחת *Variables* (יש ברירות מחדל, לא חובה):

| שם | ברירת מחדל | משמעות |
|---|---|---|
| `MIDWEEK_DAYS` | `1,2,3` | שלישי, רביעי, חמישי. `0`=שני, `6`=ראשון |
| `MIN_LAP_SECONDS` | `120` | מקטע קצר מזה נזרק |

`MIDWEEK_DAYS` קובע רק מה נחשב אימון אינטרוולים. רכיבה ביום אחר
נכנסת אוטומטית כרכיבה ארוכה, וריצה נכנסת תמיד לתצוגת הריצה.
לשבוע העבודה הישראלי במלואו: `MIDWEEK_DAYS = 6,0,1,2,3`.

### 3. תוקף

הטוקן תקף כשנה. כשהסנכרון מתחיל להיכשל באימות — הרץ שוב את `garmin_auth.py`
ועדכן את ה-secret.

## מה הסנכרון עושה

1. מושך פעילויות מ-10 הימים האחרונים ומנתב כל אחת:

   | מה | לאן |
   |---|---|
   | אופניים ביום אמצע שבוע | `interval` — מקטעי העבודה בלבד |
   | אופניים בכל יום אחר | `long` — שורת סיכום אחת לרכיבה |
   | ריצה | `run` — קצב לכל מקטע |
   | שחייה, כוח, אחר | לא נכנס |

2. קורא את ה-**NP לכל מקטע ישירות מ-Garmin** — אותו ערך שמופיע בטבלת הלאפים באתר.
   אם הוא חסר, הוא מחושב מזרם ההספק: ממוצע נע 30 שניות, בחזקת 4, שורש רביעי.
3. מפריד מקטעי עבודה ממנוחות לפי חיתוך באמצע טווח ההספק. בריצה החיתוך לפי קצב.
4. **לא מסווג לאזורים.** הוא רושם NP ומשך, והדאשבורד מסווג לבד (ראה למטה).
5. מוסיף ל-`laps.csv` ודוחף. אימון שכבר קיים לא נדרס.

הרצה ידנית: **Actions → Sync Garmin → Run workflow**.

## איך נקבע האזור

הסף לא מוגדר ידנית אלא מוערך מהנתונים עצמם, ומתעדכן לבד עם הכושר.

1. כל מקטע מתורגם ל**הספק שקול ל-20 דקות** לפי חוק החזקה של עקומת ההספק–זמן:
   `NP × (משך / 1200) ^ 0.06`. כך מקטע של 3 דקות ב-270W ומקטע של 20 דקות
   ב-235W מתחרים באותה סקאלה.
2. הסף הוא 95% מהמאמץ החזק ביותר אחרי התרגום.
3. כל מקטע מקבל אזור Coggan לפי אחוז מהסף, ואזור האימון הוא זה
   שבו בילה **הכי הרבה זמן עבודה** — לא ממוצע פשוט, כדי שאימון פירמידה
   או over-under יסווג לפי הגוף שלו ולא לפי הקצה.
4. אזורים קיצוניים ממופים פנימה: Z1 נכנס לתצוגת Z2, ו-Z5/Z6 לתצוגת Z4.
   האזור האמיתי והפילוח המלא מוצגים מתחת לגרף האימון הבודד.

בסרגל הצד אפשר לעבור לסף ידני. עמודת `zone` ב-CSV דורסת את הסיווג
האוטומטי לאימון מסוים, אם רוצים לקבע אותו.

מודל Critical Power נבחן ונפסל: הוא מניח שכל מאמץ הוא מקסימלי, ובאימוני
אימון רוב המקטעים תת-מקסימליים — על הנתונים כאן הוא נתן CP של 147W
במקום סף אמיתי של כ-230W.

## פורמט הנתונים

```csv
workout,sport,kind,zone,lap,secs,np,pace,hr,cad
2026-07-21,bike,interval,,1,300,214,,146,91
2026-07-18,bike,long,,1,16200,175,,140,86
2026-07-20,run,interval,,1,600,,292,153,178
```

| עמודה | משמעות |
|---|---|
| `sport` | `bike` או `run` |
| `kind` | `interval` או `long` |
| `zone` | ריק = סיווג אוטומטי. `Z2`/`Z3`/`Z4` = קיבוע ידני |
| `secs` | משך המקטע. בלעדיו הסיווג פחות מדויק |
| `np` | ואט, לאופניים |
| `pace` | שניות לק״מ, לריצה |

קבצים בפורמט הישן (בלי `sport`/`kind`/`secs`) עדיין נטענים —
העמודות החסרות מתמלאות בברירות מחדל.
